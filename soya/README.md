# soya

## 現在の最新コードについて

現在、最新の実装は `kashi` フォルダ内のフルートプログラム（`Flute.pde`）です。

歌詞表示や波形表示などの追加機能は、このフルートプログラムに反映されています。

一方で、他の楽器プログラムについてはまだ同様の更新が反映されておらず、最新の状態ではありません。

## 追加部分の識別について

フルートプログラムでは、自身が新たに追加した箇所が分かりやすいように、コード中に以下のコメントを記載しています。

```text
//-------s
（追加部分）
//-------f
```

この範囲が新たに実装・追加したコードです。

なお、他の楽器プログラムには現在この区分けが反映されていません。今後、全ての楽器プログラムについても同様に追加部分が分かるよう整理・改良する予定です。

### 1. FFT スペクトラム解析

**該当箇所**: import文（L3-5）、グローバル変数（L14-15, L22-29）、`setup()` 内の初期化（L105-106）、`draw()` 内の処理（L147-163）

#### 概要

音声出力の左チャンネルに対してリアルタイムで FFT（高速フーリエ変換）解析を行い、周波数スペクトラムを取得する。

#### 仕様

| 項目 | 値 |
|---|---|
| FFTサイズ | `out.bufferSize()`（1024サンプル） |
| サンプルレート | `out.sampleRate()` |
| 表示バンド数 | 16 |
| デシベル範囲 | 0 dB 〜 80 dB |

#### 処理フローa

1. `fft.forward(out.left)` で左チャンネルの波形データをFFT解析
2. `updateSpectrum()` で16バンドに分割し、各バンドのデシベル値を算出（`20 * log(value + 1)`）
3. 値を `minDB` 〜 `maxDB` の範囲にクランプ

#### パフォーマンス計測

- `System.nanoTime()` を用いてFFT処理時間をミリ秒単位で計測し、コンソールに出力

### 2. Arduino シリアル通信（FFTデータ送信）

**該当箇所**: グローバル変数（L14, L20）、`setup()` 内の初期化（L112-113）、`sendFFTToArduino()`（L232-239）

#### 概要

FFT解析で得た16バンドのスペクトラムデータをシリアル通信でArduinoに送信する。

#### 仕様

| 項目 | 値 |
|---|---|
| ボーレート | 115200 |
| ポート | `Serial.list()[1]` |
| 送信データ | 16バンド × 1バイト（0〜255） |
| 送信タイミング | 毎フレーム（`draw()` ごと） |

#### 処理フロー

1. 各バンドのデシベル値を 0〜255 の整数にマッピング
2. `myPort.write(val)` で1バイトずつ送信（合計16バイト/フレーム）
3. 送信バイト数を `sendBytes` でカウント

### 3. 歌詞表示（カラオケ風ハイライト）

**該当箇所**: グローバル変数（L33-41）、`draw()` 内の呼び出し（L170-174）、`drawLyrics()`（L256-281）、`updateLyricIndex()`（L302-335）、`drawKaraokeText()`（L410-448）

#### 概要

楽曲の再生進行に合わせて歌詞をカラオケ風に表示する。現在再生中の歌詞が左から右へ黄色にハイライトされる。

#### 仕様

| 項目 | 値 |
|---|---|
| 表示領域 | 画面中央、Y=250〜330 の帯状領域 |
| 歌詞データ | `lyrics[]` 配列（現在2行：「きらきら ひかる」「おそらの ほしよ」） |
| フォント | YuMin-Medium、32pt |
| 未通過テキスト色 | 白 (`255`) |
| 通過済みテキスト色 | 黄 (`255, 255, 0`) |
| 背景色 | ダークブルー (`30, 30, 50`) |

#### カラオケ進行ロジック

1. `songTotalDuration` を全音符から計算（最後の音の開始時間 + 長さ）
2. 経過時間に基づき `currentLyricIndex` を切り替え
3. 各歌詞セグメント内の進行率 `lyricProgress`（0.0〜1.0）を算出
4. `drawKaraokeText()` でクリッピングを使い、進行率に応じて黄色部分を左から描画

### 4. 音程バー（Pitch Bar）

**該当箇所**: グローバル変数（L52-55）、`draw()` 内の呼び出し（L177）、`drawPitchBar()`（L452-574）、`noteNameToMidi()`（L576-594）

#### 概要

楽曲の各音符をピアノロール風のバーで視覚化し、再生の進行に合わせてバーがハイライトされる。音ゲーやカラオケの音程ガイドに類似した表示。

#### 仕様

| 項目 | 値 |
|---|---|
| 表示領域 | X=60, Y=370, 幅=1680, 高さ=240 |
| 音程範囲 | C5 〜 A5 |
| 音名ラベル | C5, D5, E5, F5, G5, A5（左端に表示） |
| 背景色 | 半透明ダークブルー (`15, 15, 30, 220`) |

#### バーの色分け

音程の高さに応じてグラデーション配色される：

| 音程 | 色 |
|---|---|
| 低音（C5付近） | 青 (`80, 160, 255`) |
| 中音（E5付近） | 緑 (`80, 230, 160`) |
| 高音（A5付近） | オレンジ (`255, 180, 60`) |

- 未通過部分は暗い色（`dimColor`: 元の色を `(30,30,50)` に向かって70%暗くした色）
- 通過済み部分は明るい色（`brightColor`）

#### 判定バー（赤い縦線）

再生の現在位置を示す赤い縦線が左から右へ移動する。

| 項目 | 値 |
|---|---|
| メインライン | 赤 (`255, 80, 80`)、太さ2px |
| グロー効果 | 半透明赤 (`255, 60, 60, 60`)、太さ6px |
| 三角マーカー | バー上部に赤い三角形 |

#### 音名→MIDI変換（`noteNameToMidi()`）

音名文字列（例: `"C5"`, `"A#5"`）をMIDIノート番号に変換するユーティリティ関数。シャープ（`#`）にも対応。

### 5. 星アニメーション

**該当箇所**: グローバル変数（L44-49）、`setup()` 内の初期化（L91-97）、`drawStars()`（L388-408）

#### 概要

歌詞表示エリアの背景に流れ星のようなアニメーションを描画する。

#### 仕様

| 項目 | 値 |
|---|---|
| 星の数 | 50個 |
| 表示範囲（Y） | 250 〜 330 |
| 星のサイズ | 2 〜 6 px（ランダム） |
| 移動方向 | 左方向 |
| 移動速度 | 0.3 〜 1.0 px/frame（ランダム） |
| 明滅 | `sin(frameCount * 0.05 + i)` による周期的な明るさ変化 |

- 画面左端を越えた星は右端にリセットされ、Y座標も再ランダム化される

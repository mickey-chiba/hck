# MFCC による楽器音色評価システム ドキュメント

## 概要

このシステムは、Processing で合成したフルート音が「実際の楽器の音にどれだけ似ているか」を  
**MFCC（Mel-Frequency Cepstral Coefficients：メル周波数ケプストラム係数）** を使って数値で評価するものです。

---

│   ├── flute.pde              メイン（再生・キー入力・波形描画）
│   ├── InstrumentModule.pde   合成楽器クラス（波形・フィルタ・ADSR）
│   └── MFCCAnalyzer.pde       MFCC計算・描画・楽器判定
│

│   ├── compute_double_bass_mfcc.py    コントラバス参照MFCC計算

## MFCCとは

**人間の聴覚特性を模倣した音色の特徴量**です。  
「低音を細かく、高音を粗く」知覚する人間の耳の性質をフィルタ設計に反映させ、  
音色（倍音の構造・スペクトルの形状）を 13 個の数値にコンパクトに圧縮します。

### 処理の流れ

```
音声バッファ
    ↓
ハミング窓          ← 信号の端のノイズ（不連続点）を除去
    ↓
DFT（離散フーリエ変換） ← 時間軸 → 周波数軸に変換
    ↓
メルフィルタバンク    ← 人間の聴覚に合わせた26個の三角フィルタを適用
    ↓
対数変換            ← 音量の大小差を圧縮（人間の音量知覚に対応）
    ↓
DCT-II             ← 相関を除去して13個の係数に圧縮
    ↓
MFCC 係数 c1〜c13
```

### 各係数の意味

| 係数 | ラベル | 意味 | 備考 |
|------|--------|------|------|
| c1 | Energy | 全体のエネルギー量 | 常に大きな負の値。音量に対応 |
| c2 | Bright | 低域 vs 高域のバランス | 正 → 明るい音、負 → 暗い音 |
| c3 | Round | スペクトルの滑らかさ | 負 → 柔らかい音（フルートらしい） |
| c4 | Hard | 中域の形状 | 正 → 硬い音色 |
| c5 | Sharp | 高域ピーク成分 | |
| c6〜c13 | Harm.1〜8 | 各倍音成分の強度 | 正 → その倍音が強い |

> **注意：** MFCCは音の「高さ（ピッチ）」を直接表すものではありません。  
> 音色（どんな楽器らしいか）を表す特徴量です。

## 操作方法

| キー | 動作 |
|------|------|
| `a` | 楽曲再生（きらきら星） |
| `m` | MFCC解析を実行（再生中に押すと音色を取得） |

### 正しい手順

1. `a` キーで再生を開始する
2. 音が出ている間に `m` キーを押す
3. 画面下部に MFCC バーグラフと楽器判定結果が表示される

> 無音状態で `m` を押すと c1 が約 -600 になり他の係数は 0 になります。  
> これは計算が正しく動いているサインですが、無音のため音色情報がありません。

## 画面の見方

### バーグラフ（上部）

- **青いバー（上向き）** → その係数の値が正
- **赤いバー（下向き）** → その係数の値が負
- 各バーの下に係数番号（c1〜c13）と意味ラベルが表示されます

### 数値テーブル（右側）

各係数の値を色分けで表示します。

| 色 | 意味 |
|----|------|
| 黄色 | 絶対値 > 20（特に大きい値） |
| 水色 | 絶対値 5〜20（中程度） |
| グレー | 絶対値 < 5（小さい値） |

### 楽器判定結果（下部）

合成音のMFCCと4楽器の参照MFCCのユークリッド距離を比較します。

```
→ Closest: Flute   dist:XX.X
```

**距離バー**：緑（短い＝近い）〜赤（長い＝遠い）で4楽器分表示されます。  
バーが短く緑色の楽器が「最も音色が近い楽器」です。

## 楽器判定の仕組み

### ユークリッド距離

合成音の MFCC ベクトルと各楽器の参照ベクトルの距離を計算します。

```
距離 = √( (c1_合成 - c1_参照)² + (c2_合成 - c2_参照)² + ... + (c13_合成 - c13_参照)² )
```

距離が最も小さい楽器 = 最も音色が近い楽器として判定されます。

### 4楽器の参照MFCC（grand_mean）

実音源から計算した各楽器らしい MFCC の平均ベクトルです。

| 係数 | Flute | Trumpet | Double Bass | Glockenspiel |
|------|------:|--------:|------------:|-------------:|
| c1 | -31.9 | -26.4 | -31.2 | -48.2 |
| c2 | +4.3 | +7.9 | +12.3 | +3.4 |
| c3 | -6.5 | -3.1 | +5.8 | -1.3 |
| c4 | -4.9 | -1.6 | +4.2 | +0.2 |
| c5 | -2.5 | -2.3 | +2.8 | +3.8 |
| c6 | -0.9 | -2.5 | +1.9 | +1.6 |
| c7 | +0.8 | -2.2 | +1.3 | +0.4 |
| c8 | +1.6 | -2.0 | +0.8 | +0.5 |
| c9 | +1.8 | -1.8 | +0.2 | -0.4 |
| c10 | +2.0 | -1.8 | +0.3 | +0.4 |
| c11 | -2.8 | -2.0 | +0.2 | +0.5 |
| c12 | -5.3 | -1.6 | +0.1 | +0.9 |
| c13 | -1.0 | -0.2 | +0.1 | +0.0 |

#### 各楽器の特徴

**フルート（Flute）**
- c3〜c4 が強く負 → スペクトルが滑らかで柔らかい音色
- c7〜c10 が正 → 中高域の倍音が適度に存在

**トランペット（Trumpet）**
- c7〜c10 が全て負 → 金管楽器特有の密な倍音構造
- c2 が高め → 高域エネルギーが豊富（明るい音）

**コントラバス（Double Bass）**
- c2〜c6 が全て正 → 低域エネルギーが突出して強い
- c3 が正（+5.8）← フルートは -6.5 と対照的

**グロッケンシュピール（Glockenspiel）**
- c1 が -48 と特に低い → 金属打楽器特有の硬い音
- c3〜c4 がほぼ 0 → スペクトルが比較的フラット

## 参照データの作成方法（Python スクリプト）

### 使い方

```bash
python3 compute_flute_mfcc.py
```

実行すると `flute_mfcc_reference.json` が生成されます。

### 処理の流れ

1. 指定フォルダ内の MP3（または WAV）ファイルを検索
2. ffmpeg で WAV に変換（MP3 の場合）
3. 各ファイルをフレーム分割（1024 サンプル、512 サンプルシフト）
4. フレームごとに MFCC を計算
5. ファイルごとの平均 MFCC を計算
6. 全ファイルの grand mean（楽器らしい MFCC）を計算
7. JSON に保存

### 音源の条件

| 項目 | 設定 |
|------|------|
| サンプルレート | 44100 Hz |
| フォーマット | MP3 または WAV |
| ファイル数 | 10〜20 ファイル推奨 |
| 音源の種類 | 単音（1音符ずつ録音されたもの）が最適 |

### パラメータ一覧

| パラメータ | 値 | 説明 |
|------------|-----|------|
| `SAMPLE_RATE` | 44100 | サンプリング周波数 |
| `N_MFCC` | 13 | 出力する係数の数 |
| `N_FILTERS` | 26 | メルフィルタの数 |
| `FFT_SIZE` | 1024 | FFT サイズ |
| `HOP_SIZE` | 512 | フレームシフト（50%オーバーラップ） |
| `F_MIN` | 80.0 Hz | メルフィルタの最低周波数 |
| `F_MAX` | 8000.0 Hz | メルフィルタの最高周波数 |

> **Processing 側と必ず同じ値にすること。**  
> 値が違うと参照データと合成音の MFCC が比較できなくなります。

## MFCCAnalyzer.pde の主要メソッド

| メソッド | 役割 |
|----------|------|
| `MFCCAnalyzer()` | 初期化・メルフィルタバンクの構築（起動時1回のみ） |
| `analyze(out)` | AudioOutput から音声バッファを取得し MFCC を計算 |
| `draw()` | バーグラフ・数値テーブル・楽器判定を描画（毎フレーム） |
| `buildMelFilterBank()` | 三角メルフィルタ行列を構築 |
| `computeMFCC(signal)` | ハミング窓 → DFT → メルフィルタ → DCT の計算本体 |
| `euclideanDist(ref)` | 参照ベクトルとのユークリッド距離を計算 |
| `closestInstrument()` | 4楽器中で最も近い楽器名を返す |

## よくあるトラブル

### c1 が -600 近くになり他がすべて 0

**原因：** 無音状態で `m` を押した  
**対処：** `a` で再生後、音が出ている間に `m` を押す

### バーが画面からはみ出る

**原因：** スケールが合っていない  
**対処：** `draw()` 内の `scales[]` 配列の値を調整する

### 文字が文字化けする

**原因：** Processing のデフォルトフォントは ASCII のみ対応  
**対処：** ラベルを英語にする（日本語を使う場合は `createFont()` でフォントを指定）

### 判定結果が常に同じ楽器になる

**原因：** 再生音と参照データのパラメータが一致していない可能性  
**対処：** Python スクリプトと `MFCCAnalyzer.pde` の `fftSize`・`numFilters`・`fMin`・`fMax` が同じ値か確認する
